# 🤖 DF-VPN-Bot

Telegram-бот для продажи VPN-подписок: каталог тарифов, оформление заказа, подтверждение оплаты вручную администратором и автоматическая выдача ключа клиенту.

> Ранее этот бот жил внутри репозитория [DF_IPTV](https://github.com/Dolov07KBR/DF_IPTV) вместе с плейлистами. Для удобства код разнесён по разным репозиториям: здесь — бот, там — m3u-плейлисты.

## ✨ Возможности

- 📋 Каталог тарифов с ценами (`/plans`)
- 🧾 Создание заказа и хранение его в SQLite
- 💳 Приём подтверждения оплаты (текст или скриншот) от клиента
- 🔔 Уведомление администратора о новом платеже с кнопкой подтверждения
- 🔑 Автоматическая отправка VPN-ключа клиенту после подтверждения
- 📂 Просмотр истории своих заказов (`/myorders`)

## 🗂️ Тарифы по умолчанию

| Код  | Название   | Цена   | Срок      |
|------|------------|--------|-----------|
| `1m`  | 1 месяц   | 299 ₽  | 30 дней   |
| `3m`  | 3 месяца  | 799 ₽  | 90 дней   |
| `12m` | 12 месяцев| 2499 ₽ | 365 дней  |

Тарифы задаются прямо в коде (`PLANS` в `vpn_sales_bot.py`) — поменяйте значения под себя.

## 🚀 Быстрый старт

1. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Скопируйте файл переменных окружения:

   ```bash
   cp .env.example .env
   ```

3. Заполните `.env`:

   | Переменная      | Назначение                              |
   |-----------------|------------------------------------------|
   | `BOT_TOKEN`     | Токен бота, выданный [@BotFather](https://t.me/BotFather) |
   | `ADMIN_CHAT_ID` | Telegram ID администратора (получает уведомления об оплатах и подтверждает их) |
   | `DB_PATH`       | Путь к файлу SQLite базы данных заказов |

4. Запустите бота:

   ```bash
   python vpn_sales_bot.py
   ```

## 🔁 Как это работает

1. Клиент пишет `/plans` → выбирает тариф → бот создаёт заказ в БД со статусом `pending_payment`.
2. Клиент присылает боту скриншот или текст с подтверждением оплаты → статус меняется на `paid_unconfirmed`, администратору (`ADMIN_CHAT_ID`) уходит уведомление с кнопкой «Подтвердить оплату».
3. Администратор нажимает кнопку → бот генерирует ключ, меняет статус заказа на `approved` и отправляет ключ клиенту в личные сообщения.
4. Клиент в любой момент может посмотреть свои последние заказы через `/myorders`.

Все заказы хранятся в локальной SQLite базе (`vpn_bot.sqlite3` по умолчанию), таблица `orders` создаётся автоматически при первом запуске.

## ⚠️ Важно перед продакшеном

Это шаблон/заготовка, а не готовое к продажам решение. Перед реальным использованием обязательно добавьте:

- реальную интеграцию с платёжным провайдером (сейчас подтверждение оплаты — вручную администратором);
- реальную выдачу VPN-конфигов вместо заглушки `vpn://example-config/order-{id}`;
- защиту от повторной отправки / накрутки заказов и базовый анти-фрод;
- логирование действий администратора и резервное копирование БД;
- юридически корректные оферту и политику обработки персональных данных.
